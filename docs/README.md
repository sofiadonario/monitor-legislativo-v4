## 🏗️ System Architecture

**Unified Service Stack:**
- **Frontend**: R-Shiny application with responsive UI
- **Backend**: Integrated R modules and functions
- **Database**: PostgreSQL (Cloud SQL) with 134,014+ documents
- **Cache**: Redis for performance optimization
- **Deployment**: Google Cloud Run with automated CI/CD

## 🎯 Academic Focus

**Research Areas:**
- Brazilian transport legislation analysis
- Geographic policy mapping and visualization
- Legislative trend analysis and forecasting
- ABNT-compliant academic citation generation
- Machine learning for legal document classification

**Target Users:**
- Academic researchers in law and public policy
- Graduate students in Brazilian legislative studies  
- Government policy analysts
- Legal professionals specializing in transport law

## 📊 Key Features

- **Real-time Legislative Search**: 134k+ authentic Brazilian documents
- **Geographic Analysis**: Interactive maps with municipal-level detail
- **Advanced Analytics**: ML-powered document classification and trend analysis
- **Export Capabilities**: Academic-ready data exports in multiple formats
- **Citation Generator**: ABNT-compliant reference generation
- **Performance Optimized**: Sub-2-second search with Redis caching
