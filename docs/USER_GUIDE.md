# Monitor Legislativo v4 - User Guide

## Welcome to Monitor Legislativo v4

Monitor Legislativo v4 is an advanced academic research platform for analyzing Brazilian legislative data. This consolidated R architecture provides powerful tools for legal research, geographic analysis, and academic workflow management.

## Getting Started

### Accessing the Platform

1. **Web Access**: Visit your deployed application URL
2. **Health Check**: The platform includes automatic health monitoring
3. **Browser Support**: Works with modern browsers (Chrome, Firefox, Safari, Edge)

### First Steps

1. **Explore the Interface**: Familiarize yourself with the tabbed navigation
2. **Run a Search**: Try searching for transportation-related legislation
3. **View Results**: Explore documents, maps, and analytics
4. **Export Data**: Download results for your research

## Core Features

### 🔍 LexML Enhanced Search

**Advanced Legislative Search Engine**

- **Vocabulary-Aware Search**: Uses SKOS vocabulary for intelligent query expansion
- **Real-time Results**: Fast search with <2 second response times
- **Academic Citations**: Automatic citation generation in multiple formats

**How to Search:**
1. Navigate to the "🔍 Busca LexML" tab
2. Enter your search terms (e.g., "transporte público")
3. Use advanced filters for specific document types
4. Review results with enhanced metadata

**Search Tips:**
- Use specific terms for better results

## Troubleshooting

### Common Issues

**Slow Search Results:**
- Check your internet connection
- Try more specific search terms
- Use date range filters to limit scope
- Contact support if performance persists

**Export Problems:**
- Ensure pop-ups are enabled for downloads
- Try smaller data sets for large exports
- Check available disk space
- Verify file format compatibility

**Map Loading Issues:**
- Refresh the page if maps don't load
- Check browser JavaScript settings
- Try zooming in/out to refresh tiles
- Clear browser cache if persistent

**General Troubleshooting:**
1. Refresh the page (Ctrl+F5 or Cmd+Shift+R)
2. Clear browser cache and cookies
3. Try a different browser
4. Check internet connection stability
5. Contact technical support

## Frequently Asked Questions

### General Questions

**Q: Is Monitor Legislativo v4 free to use?**
A: Yes, the platform is designed for academic research and is freely available.

**Q: Can I use this for commercial research?**
A: The platform is primarily designed for academic use. Check terms of service for commercial usage.

**Q: How current is the legislative data?**
A: Data is updated regularly from official government sources, with real-time updates when available.

### Technical Questions

**Q: Can I access this platform offline?**
A: No, Monitor Legislativo v4 requires an internet connection for accessing current legislative data.

**Q: What data formats can I export?**
A: Multiple formats including CSV, Excel, JSON, BibTeX, and PDF.

**Q: Is my research data private?**
A: Search queries and research sessions are not stored permanently. Export your important work locally.

### Research Questions

**Q: How do I cite this platform in my research?**
A: Use the citation generator within the platform, or cite as "Monitor Legislativo v4 - Brazilian Legislative Research Platform."

**Q: Can I integrate this with other research tools?**
A: Yes, export functions support integration with reference managers and statistical software.

**Q: How accurate is the geographic analysis?**
A: Geographic data is sourced from IBGE (Brazilian Institute of Geography and Statistics) for maximum accuracy.
